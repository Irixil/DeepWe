# 隐私与模型数据路径

深蓝把独立私密支持、由本人控制的 Memory 和自愿进入的双人复盘放在不同的授权边界内。

## 本地存储

后端使用 SQLite。默认数据目录为后端工作目录下的 `.data`；部署者负责数据目录权限、备份、删除及持久化配置。

源码仓库不包含用户数据库、生产环境、账号、原始私聊或内部测试截图。回归测试中的案例为虚构测试材料。

## 模型调用

浏览器访问 DeepWe API，后端按具体功能组装模型输入并调用配置的供应商。模型密钥仅应保存在服务端环境中。

私密支持可能使用本人输入、当前对话上下文及本人开启的有效 Memory。共享生成使用各自确认分享的摘要，不应直接把双方原始私聊合并发送。具体输入边界由后端实现决定。

“不向另一位参与者公开”不代表“文本永远留在设备内”。配置真实模型后，相关输入会发送到相应模型供应商，部署者应说明其实际供应商、存储区域、留存政策和费用。演示回应与真实模型能力不同。
